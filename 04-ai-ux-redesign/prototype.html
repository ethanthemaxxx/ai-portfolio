Speculative redesign — unaffiliated, unsolicited, not commissioned by anyone. This is an independent UX concept for the run-inspection screen of AI agent nodes in workflow automation tools (n8n, Make, Zapier and similar). It uses no company’s logo, brand or product assets, and it is not a product of, or endorsed by, any of them. Every number, order, supplier and person shown is synthetic.

Agent Run Inspector

The screen an operator opens when an AI agent has just run against their real business data and something now has to leave the building. Redesigned as a decision surface rather than a data viewer. Press Run workflow — the streaming, the uncertainty, the tool calls, the failure and the human gate are all live, not screenshots.
