Speculative redesign — unaffiliated, unsolicited, not commissioned by anyone. An independent UX concept for the run-inspection screen of AI agent nodes in workflow automation tools (n8n, Make, Zapier and similar). It uses no company's logo, brand or product assets, and is not a product of, or endorsed by, any of them. Every number, order, supplier and person shown is synthetic.

Portfolio piece · Product design · AI interfaces

What should a screen show you when the AI is confidently wrong?

An agent just ran against your real business data, and a purchase order is about to go out. Three of four line items are right. On the fourth it wrote a fluent, specific, completely false sentence about a supplier's lead time. A run that crashes is easy — the interesting failure looks exactly like a success.

The five problems it answers

01

Streaming — the wait is filled with a commitment, not a spinner. The agent publishes its plan before the first tool call, and the plan's last line is the limit of its own authority.

02

Confidence — no uncalibrated "87% sure" badge. Every value is verified, derived or assumed, and only assumed gets colour.

03

Tool transparency — one line per call, the real payload one click away.

04

Graceful failure — the model is never asked to grade itself. A deterministic check re-reads the record and shows both values side by side.

05

Human-in-the-loop — the pause goes before the irreversible step. Partial approval, editing with the original kept, and an expiry that defaults to not sending.

No sign-up, no data collected, nothing leaves your browser. The prototype is a single self-contained HTML file — no build step, no dependencies, and zero network requests once loaded.

No usability testing was run on this design. There are no task-time or error-rate numbers anywhere in it, because none were measured — the case study argues from design reasoning and states what it would test first.
